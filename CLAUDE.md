# Август-герой — прототип (демо-комната)

2D-платформер для Android про мальчика-супергероя на крышах вечернего города. Игра для ребёнка 4–6 лет, мультяшный рисованный стиль. Сейчас делаем только **демо-комнату**: проверить персонажа, анимацию и три механики — прыжок, прилипание/лазанье по стенам, выстрел паутиной.

Главный приоритет — чтобы выглядело и ощущалось «как мультик»: плавно, сочно, живо. Второй приоритет — простой, понятный код без переусложнения.

## Стек

- Phaser 3 + TypeScript + Vite.
- Capacitor (Android) — подключаем на этапе 4, когда в браузере всё работает.
- Альбомная ориентация, базовое разрешение 1920×1080, `Scale.FIT`, `Scale.CENTER_BOTH`.
- Dev-сервер с `--host`, чтобы открывать с телефона по Wi-Fi.
- Никакого текста на экране, кроме debug-режима.

## Этап 1 — каркас проекта

- Vite + TS + Phaser, структура: `src/scenes/`, `src/hero/` (риг, анимации, плащ, контроллер), `src/input/`, `src/world/`, `src/config/`.
- Загрузка ассетов, сцена `DemoRoom` с фоном.
- Фон: три слоя с параллаксом (sky ~0.1, city_far ~0.3, city_mid ~0.6), лёгкое размытие дальнего слоя (postFX blur, если доступен), тёплая виньетка по краям экрана.
- Проверка: открывается в браузере, параллакс работает при движении камеры стрелками.

## Этап 2 — cutout-риг героя

- Герой — `Container` из спрайтов деталей. Иерархия: туловище → голова; плечо → предплечье → кисть; бедро → голень.
- Дальние рука и нога — копии ближних, затемнённые ~25% (`setTint`), рисуются ЗА туловищем и чуть смещены назад. Порядок слоёв спереди назад: ближняя рука, голова, туловище, ближняя нога, дальняя нога, дальняя рука, плащ.
- Все pivot-точки, смещения, масштабы и углы покоя — в `src/config/rig.json`, чтобы их можно было править без кода. Начальные значения подбери, сравнивая с `hero_full.png`.
- Debug (клавиша D): показывать pivot-точки, кости-линии и хитбокс физики.
- Процедурные анимации — повороты деталей с easing и плавным смешиванием поз (не резкое переключение):
  - **idle** — дыхание (туловище чуть масштабируется), голова слегка покачивается;
  - **run** — цикл по синусу, руки и ноги в противофазе, колено сгибается в фазе переноса, лёгкий подскок тела, наклон вперёд;
  - **jump** (взлёт: ноги поджаты, руки вверх), **fall** (руки в стороны), **land** (squash 1–2 кадра);
  - **wall_cling** / **wall_climb** — прижат боком к стене, руки по очереди тянутся вверх, ноги переступают;
  - **shoot** — ближняя рука резко вытягивается к цели, предплечье заменяется на `forearm_cuff` + `hand_open`, затем плавно возвращается.
- Плащ: `Phaser.GameObjects.Rope` + верлет-цепочка 8–10 точек, крепится к плечу. Гравитация + сопротивление воздуха + реакция на скорость героя: развевается при беге, задирается при падении, спокойно висит в idle, не проходит сквозь тело (простое ограничение — точки не уходят вперёд за линию спины).
- Герой на экране ~1/5 высоты экрана.
- Проверка: стоит, бегает и прыгает красиво, ничего не «отрывается» в суставах.

## Этап 3 — механики (Arcade Physics)

- **Бег**: разгон и торможение (не мгновенная скорость), поворот героя через `scaleX = -1` всего контейнера.
- **Прыжок**: coyote time ~100 мс, jump buffer ~100 мс, переменная высота (короткое нажатие — низкий прыжок).
- **Стены**: прилипать можно только к стенам с флагом `climbable` (визуально отличаются — кирпич с плющом). Прыгнул на стену — прилип. Держишь направление В стену — ползёт вверх; отпустил — медленно сползает; прыжок — отталкивается от стены по диагонали в обратную сторону (на ~150 мс блокируем управление в сторону стены, чтобы не прилипнуть обратно). На верхнем краю стены — автоматически вылезает на крышу.
- **Выстрел паутиной**: из руки летит снаряд, за ним тянется светящаяся нить (бирюзово-белая, с мерцанием), нить исчезает через ~0.3 с. Автоприцел: если в конусе впереди есть дрон — летит к нему. Попадание — дрон заворачивается в белый кокон (анимация обмотки), падает, отскакивает, через 3 с исчезает в облачке искорок. Перезарядка ~0.4 с.
- Управление «одной кнопкой» для ребёнка: никаких комбинаций, всё через ← → прыжок паутина.

## Демо-комната

- Уровень шириной ~2.5 экрана, камера плавно следует за героем (lerp, небольшой look-ahead по направлению движения), границы камеры по уровню.
- Пол-крыша по всей длине, 3 платформы на разной высоте, одна высокая стена для лазанья, узкий колодец из двух стен для прыжков от стены, 3 парящих дрона-мишени (пока простые симпатичные фигуры: круглый корпус + пропеллер + глазок, мягко покачиваются).
- Платформы и стены — плейсхолдеры, нарисованные кодом (Graphics или сгенерированные текстуры), но в палитре фона: тёмно-фиолетовый кирпич с тёплым закатным бликом по верхней кромке, НЕ серые прямоугольники.
- Пару декоративных объектов на крышах (трубы, антенна) для ощущения места.

## Управление

- Сенсор: большие полупрозрачные круглые кнопки. Слева ← →, справа прыжок (крупнее) и паутина. Мультитач обязателен (бег + прыжок одновременно). Кнопка при нажатии чуть уменьшается и светлеет.
- Клавиатура для отладки: стрелки, пробел — прыжок, X — паутина, D — debug.

## Сочность (juice)

Squash & stretch на прыжке и приземлении, облачко пыли при приземлении и отталкивании от стены, искорки при выстреле, лёгкая тряска камеры при попадании, мягкий шлейф частиц за героем в прыжке.

## Этап 4 — Android

- Подключить Capacitor, `npm run android`: сборка web → `cap sync` → debug APK → установка на телефон по USB (adb).
- Полный экран, альбомная ориентация, скрыть системные панели, не гасить экран во время игры.

## Порядок работы

Работай по этапам. После каждого этапа останавливайся, пиши, что проверить в браузере, и жди подтверждения. Если подбор pivot-точек рига требует визуальной проверки — делай скриншоты сцены (например, через Playwright) и смотри сам, прежде чем звать меня.
