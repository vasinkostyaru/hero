# Август-герой

2D-платформер для Android про мальчика-супергероя на крышах города. Игра для ребёнка 4–6 лет, мультяшный рисованный стиль, настроение «блокбастер». Главный приоритет — чтобы выглядело и ощущалось «как мультик»; второй — простой, понятный код без переусложнения.

## Стек и запуск

- Phaser 3 + TypeScript + Vite; Capacitor (Android).
- Высота экрана всегда 1080, ширина подстраивается под телефон (`Scale.EXPAND`). Альбомная ориентация.
- `npm run dev` — dev-сервер с `--host` (открывать с телефона по Wi-Fi). `npm run build` — tsc + сборка.
- `npm run android` — сборка → `cap sync` → debug APK → установка по USB (adb) → запуск.
- Никакого текста на экране (кроме debug).
- Клавиатура для отладки: стрелки, пробел — прыжок, X — паутина (держать — качели), D — debug, R — заново.

## Архитектура

**Сцены** (`src/scenes/`):
- `BootScene` — загрузка всех ассетов, кольцо прогресса → карта.
- `MapScene` — карта (первый экран, MAP_UI.md, `src/config/levels.json`): 9 уровней, открытые/закрытые, звёзды, текущий с ореолом и Августом; шире экрана — двигается пальцем.
- `LevelScene` — уровень (`levelId`): фон, `Level`, герой, Ворон, паутина, камера. Крупный план Ворона в начале, сбор предметов, флаги-чекпоинты. Уровни 1–2: финальная сценка (петля над героем, улетает) → победа. Уровень 3: битва с боссом на арене → вещи → победа. «Домик» — на карту, «дальше» — следующий уровень.
- `UIScene` — поверх игры, своя камера: сенсорные кнопки, слоты предметов, перья босса, «пауза» и «домик», меню паузы (blur), экран победы (обычный и над боссом), переход «кругом».

**Прогресс** — `src/progress.ts`: лучшие звёзды за уровень в localStorage; уровень открыт после прохождения предыдущего.

**Уровень** (`src/levels/`, `src/world/Level.ts`):
- Уровень — данные `LevelDef` (`levels/types.ts`, `levels/level1..3.ts`, реестр — `levels/index.ts`): номер, 3 предмета и список секций по ~1–1.5 экрана. В секции x — от её левого края, y — мировой (крыша — `GROUND_Y`).
- В секции: куски крыши (между ними — улица с тентами), платформы/стены/ящики, декор, люльки, батуты, тележки с крюком, крюки для качелей, фонари, флаг, шалуны, предметы, насест злодея, место под будущего шалуна (`slot`), арена босса (`arena`: насесты и куда падают голуби).
- Предметы несёт злодей (`carried`) и роняет каждый, зависнув над его местом; насест — чуть перед местом. Предметы босса (`boss`) выпадают у побеждённого злодея.
- `Level` строит секции подряд, запоминает объекты каждой и не рисует/не обновляет секции далеко за экраном (`cameraFilter`). Ширина мира — `Level.width`.

**Герой** (`src/hero/`): `Hero` — покадровый атлас `hero2`, сочность кодом (squash, наклон, тень, пыль); `HeroController` — Arcade Physics: бег, прыжок (coyote, buffer, переменная высота), стены с плющом, батуты, люльки, толчки шалунов, качели на паутине (маятник; держишь паутину у крюка — цепляется, отпустил — летишь).

**Мир** (`src/world/`):
- `Platforms` — атлас `platforms` (доски, леса, балка — любой длины из модулей; люлька, балкон, бельё, тележка), батуты, улица.
- `Critter` — общий шалун: попадание паутиной → кокон. `Drone` (мишень и дрон-2 с тараном), `Pigeon`, `Seagull`. Не наносят урона — толкают.
- `Crow` — злодей мира 1: на уровне ведёт вперёд по насестам, в полёте несёт вещь в клюве и роняет её над местом, в конце — сценка и улетает. Босс (уровень 3): 10 попаданий в три фазы — перелетает; зовёт голубей (неуязвим, пока они не в коконах); пикирует на героя. Повержен — роняет трусики и носок.
- `Item` — предмет уровня; `Hook` — крюк для качелей; `Web` — паутина (автоприцел, нить качелей); `Parallax`, `Ground`, `Props`, `Ambient` (флаг-чекпоинт, фонарь, дым, пылинки), `Birds`, `fx`.

**Интерфейс** (`src/ui/ItemSlots.ts`) — три слота предметов; фон слотов меняется по миру (`SlotStyle`: верёвка; полка и стол — мирам 2–3).

**Звук и вибрация** — `src/audio/feedback.ts` (ZzFX, без файлов), музыка — `music.ts` (или `assets/audio/music.ogg`, если положить).

## Ассеты

- Атласы и картинки — `public/assets/`; всё уже уменьшено до игрового размера там, где сказано в документах (в игре `setScale(1)`), остальное уменьшается заранее на canvas (`world/textures.ts`, `scaledTexture`) — без ряби по контуру.
- Исходники — `art/raw/`, скрипты обработки — `art/*.py` (нужны numpy, scipy, pillow: `pip install -r art/requirements.txt`). `art/sheet.py` режет листы, `art/clear_holes.py` убирает белый фон внутри силуэта, `art/bird_atlas.py`, `art/platforms.py`, `art/drone2.py` собирают атласы.
- Лимит текстур телефона — 4096 px: широкие картинки резать.

## Производительность (телефон: Mali-G615, 120 Гц)

- `render.batchSize: 512` в `main.ts` — обязательно: с буфером по умолчанию драйвер Mali копирует его десятки раз за кадр, кадр 25–33 мс.
- Не рисовать то, что далеко за экраном (секции `Level`).
- Мерить FPS на самом телефоне через отладку WebView (adb + Chrome DevTools Protocol), не в headless-браузере.

## Порядок работы

- Работать по этапам из GAME.md. После этапа — остановиться, написать, что проверить, ждать подтверждения.
- Визуальные вещи проверять скриншотами (Playwright) — один раз в конце этапа, headless здесь медленный (~6 к/с).
